# Python Data Analysis Project

## 📌 Project Overview

This project is a data analysis project developed using **Python and Jupyter Notebook**. The main objective of this project is to explore, clean, analyze, and extract meaningful insights from the dataset using Python.

The complete analysis was performed in **Jupyter Notebook**, making the project easy to understand and reproduce.

## 🛠️ Tools & Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🔍 Project Workflow

The project follows these main steps:

1. Importing the dataset
2. Understanding the structure of the data
3. Checking data types and missing values
4. Data cleaning and preprocessing
5. Handling duplicate and missing data
6. Performing exploratory data analysis (EDA)
7. Applying statistical and analytical operations
8. Creating visualizations
9. Extracting useful insights from the data
